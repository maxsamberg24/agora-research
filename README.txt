AGORA NETLIFY SITE

WHAT'S INCLUDED
- index.html          Homepage
- research.html       Placeholder Research page
- writing.html        Placeholder Writing page
- styles.css          Site styling
- assets/agora-hero.png

TO DEPLOY ON NETLIFY
1. Unzip this folder.
2. If replacing your existing site, drag the CONTENTS of this folder into your Netlify deploy area (or replace the corresponding files in your repo).
3. index.html is the homepage automatically.
4. Research and Writing already link to research.html and writing.html.

NOTES
- The homepage artwork contains the logo/title/tagline as part of the image. The visible Research and Writing buttons are real HTML links placed directly over the artwork, so they are clickable, keyboard accessible, and have hover/focus states.
- The inner pages are intentionally simple placeholders. Replace their content whenever you're ready.
- Fonts load from Google Fonts (Cormorant Garamond + Inter). If you want fully self-contained/offline font behavior, the CSS already includes Georgia/Arial fallbacks.
