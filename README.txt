WHAT CHANGED

- Added extremely subtle ambient motion to the background image (a slow cinematic drift/scale). It does NOT add falling leaves or alter the image itself.
- Motion automatically turns off for visitors who have reduced-motion enabled.

TO DEPLOY ON NETLIFY
1. Unzip this folder.
2. Drag the CONTENTS of this folder into your existing Netlify deploy area, replacing the previous files.
3. index.html is the homepage automatically.
4. Research and Writing link to research.html and writing.html.

NOTE ON LEAF MOVEMENT
A single JPG/PNG cannot truly animate individual leaves independently without turning the hero into video or building layered masks. This version uses very subtle whole-scene motion so the page feels alive while preserving the exact approved artwork. If you eventually want true leaves gently moving in the breeze, the cleanest next step would be a short seamless MP4/WebM hero loop based on this exact scene.
